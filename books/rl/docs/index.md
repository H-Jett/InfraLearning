# 强化学习：从基础到 LLM 后训练

> 一本"边学边记"的强化学习入门书，从 MDP、策略梯度一路讲到 RLHF、PPO、GRPO——
> 面向**熟悉深度学习与大语言模型、但没系统学过 RL** 的算法工程师。

## 这本书想解决的问题

很多做 LLM 的工程师是"被 RLHF 拽进强化学习的"：会调 PPO 的超参，却说不清
优势函数为什么要减基线、KL 惩罚到底在拦什么、GRPO 相比 PPO 省掉了哪一块。
这本书从最小的 RL 骨架（状态、动作、回报）搭起，把每个概念都补上**为什么**，
最后落到今天 LLM 后训练真正在用的那套方法。

**读者画像**：懂反向传播、Transformer、预训练与 SFT；对 RL 只有零散印象。
所以本书**不重复讲深度学习基础**，而是处处**从监督学习/LLM 的世界做类比**再讲差异
（"策略就是一个会被自己的输出反过来训练的模型"）。通用 infra 概念引用姊妹篇
《算法工程师的 Infra 入门》，多模态相关引用《多模态入门》，不重复造轮子。

## 怎么学

每章遵循「**概念 → 思考题 → 真机代码练习**」：

1. 概念讲清楚，能用小实验验证的就在 **RTX 5090** 上跑出数据来（具体数字只当示例，讲的是**规律**）；
2. 章末思考题，指向单独的答案册；
3. 附录内联本章的可运行练习代码与真机输出。

> **⚠️ 正确性优先。** RL 里"看起来对"的直觉特别多、也特别容易错（奖励设计、方差、偏差、
> 收敛条件）。本书的结论尽量交叉核对一手资料（论文原文、官方实现、权威教材），
> 查不到就宁可不写——见开发规范 `CLAUDE.md` 的查证纪律。
