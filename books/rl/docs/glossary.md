## 基础框架

<a id="agent-env"></a>
**智能体与环境（agent / environment）**：强化学习把世界拆成"做决策的智能体"和"其余一切（环境）"。
智能体在每一步观察状态、选一个动作，环境返回下一个状态和一个标量回报。学习目标是让**累积回报**最大。

<a id="mdp"></a>
**马尔可夫决策过程（MDP, Markov Decision Process）**：强化学习的标准数学骨架，通常写作五元组
$(\mathcal{S}, \mathcal{A}, P, R, \gamma)$——状态集、动作集、状态转移概率、回报函数、折扣因子。
"马尔可夫"指下一步只依赖当前状态与动作，与更早的历史无关。

<a id="reward"></a>
**回报 / 奖励（reward）**：环境在每一步给出的标量反馈信号，是**唯一**告诉智能体"好不好"的东西。
强化学习不给"正确动作"这种监督标签，只给回报——这是它和监督学习最根本的差别。

<a id="return"></a>
**累积回报（return）**：从某一时刻起，未来所有奖励的（折扣）总和
$G_t = \sum_{k\ge 0} \gamma^k r_{t+k}$。RL 优化的是它的期望，而不是单步奖励。

<a id="discount"></a>
**折扣因子（discount factor, $\gamma$）**：$0 \le \gamma \le 1$，衡量"未来的奖励打几折"。
越接近 1 越看重长期回报，越接近 0 越短视；它也让无限长任务的累积回报保持有限。

## 策略与价值

<a id="policy"></a>
**策略（policy, $\pi$）**：从状态到动作（分布）的映射 $\pi(a\mid s)$，即智能体的"行为方式"。
在 LLM 后训练里，语言模型本身就是策略——给定上文，输出下一个 token 的分布。

<a id="value"></a>
**价值函数（value function）**：在策略 $\pi$ 下，某状态（或状态-动作对）的**期望累积回报**。
状态价值记 $V^\pi(s)$，动作价值记 $Q^\pi(s,a)$。价值是"从这里往后大概能拿多少分"的估计。

<a id="advantage"></a>
**优势函数（advantage, $A$）**：$A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$，
衡量"在状态 $s$ 选动作 $a$ 比平均水平好多少"。策略梯度里常用它替代原始回报以降低方差。

## 学习范式

<a id="on-off-policy"></a>
**on-policy / off-policy**：用来更新策略的数据是不是由**当前这个策略**产生的。
on-policy（如 PPO）只用当前策略最近采的数据；off-policy（如 Q-learning）可以复用旧策略/回放的数据。

<a id="exploration"></a>
**探索与利用（exploration vs exploitation）**：利用是"选目前看起来最好的动作"，
探索是"试试没试过的动作以获得更多信息"。两者存在张力，是 RL 特有的核心难题。
