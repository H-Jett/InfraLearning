# 学习路线图 (Roadmap)

> **总目标**：从一名**只做过纯文本 LLM** 的算法工程师出发，系统吃透多模态——
> 看懂主流 VLM 的每一个设计选择、能自己训一个、能把它跑快、能评得准，
> 并把视野延伸到生成（扩散）与全模态（音频）。
>
> 分七部分，由浅入深、前后依赖。这是一份**活的大纲**：随学习进度和兴趣随时调整。
> 状态标记：✅ 已完成 · 🔜 进行中 · ⬜ 待学。

**你已有的基础**（本书假定你会，不再重复讲）：Transformer、注意力、tokenizer、
预训练/SFT 流程、分布式训练常识。**本书要补的**：视觉侧的表征、图文如何对齐、
VLM 架构与训练范式、多模态特有的工程问题。

## 关于实战项目

章节练习是"看我跑"，**实战项目是你自己写**：我给题目、骨架和**自动评分脚本**，你实现、跑分、我 review。

项目**不单独成章**，而是排在**所属部分的最后、或某个关键技术节点之后**（见上面各部分表格里的 🛠 行），
跟着那部分一起做。频率刻意压得低——**绝不一章一个**，同一部分最多一个，**全书 5 个**，
每个都覆盖一整部分（或一项关键技术）的要点。零碎的小练习交给章节附录的 `exercises/`，不占你时间。

骨架代码在仓库根的 `projects/PN-xxx/`（带 `TODO`），`python check.py` 自动打分
（对照 transformers 等独立真源，不是对照我的实现）。参考实现默认不入库——先自己写。
