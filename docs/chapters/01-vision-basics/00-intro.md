# 第一部分 · 从 LLM 到 VLM：视觉表征基础

> **这部分回答一个问题**：图像这种连续信号，怎么变成 Transformer 能处理的东西？

如果你只做过纯文本 LLM，多模态最陌生的地方其实不在"多模态"三个字，而在**视觉侧**：
一张图没有词表、没有先后顺序、也没有天然的语义单元，凭什么能和文本塞进同一个模型？

这一部分把地基打好，之后所有 VLM 架构（第二部分）、训练范式（第三部分）、
工程问题（第四、五部分）都建立在这里的几个概念之上。

## 读这部分时请随身带着的一个念头

**Transformer 只认 `[序列长度, 隐藏维度]`。**
所有模态的"入模"工作，本质上都是在想办法把自己变成这个形状；
所有多模态的架构分歧，本质上都是在争论"这个转换该怎么做、要花多少 token"。
